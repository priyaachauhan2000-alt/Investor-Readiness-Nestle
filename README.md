# Nestlé India Investor Readiness Dashboard

This project is a Streamlit-based Investor Readiness Dashboard developed for Nestlé India.

## Features

- Executive Summary
- Financial Projections
- Product Revenue Analysis
- Pricing Scenarios
- Unit Economics
- Market Sizing
- Growth Metrics

## Technology

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
